<h1 align="center">Raman's Personal Portfolio</h1>

Welcome to my personal portfolio! This site showcases my development projects, skills, and experience. Built with modern web technologies including [Remix](https://remix.run/), [Three.js](https://threejs.org/), and [Framer Motion](https://www.framer.com/motion/).

## Install & Run Locally

Make sure you have Node.js `19.9.0` or higher and npm `9.6.3` or higher installed. 

1. Install dependencies:
```bash
npm install
```

2. Start the local development server:
```bash
npm run dev
```

3. To view the components storybook:
```bash
npm run dev:storybook
```

## Deployment

This site is optimized for deployment on Cloudflare Pages.

```bash
npm run deploy
```
